Fraud Prevention

200+ Fraud Signals on Every Session

ID verification fraud does not come from one direction. Hypersign layers multiple independent detection methods so that attackers who defeat one check are stopped by another.

Layer 1: Document-Level

  • Template matching against certified reference database
  • Security feature detection: holograms, microprint, watermarks
  • Portrait integrity: substituted portraits detected
  • Biographic data tamper via print-layer artefact analysis
  • Document liveness: screen captures and printouts blocked

Layer 2: Data-Level

  • MRZ checksum validation (character-by-character)
  • Cross-validation: visual zone, MRZ, and barcode
  • Date logic checks (issue date, expiry, age consistency)
  • Issuing state consistency (document number format)

Layer 3: Session-Level

  • Duplicate face detection across all account sessions
  • Duplicate document number detection
  • Device & IP risk scoring (VPN, Tor, proxy, emulator)
  • Velocity checks (multiple submissions, same device)
  • Blocklist matching: face hash, document number, device fingerprint

Layer 4 Biometric (with Liveness + Face Match)

  • Passive liveness: real person vs. printed photo or screen replay
  • Active liveness: challenge-response to defeat video replay
  • Deepfake detection: AI-generated faces and face-swap attacks
  • 1:1 face match: live selfie matched to document portrait
