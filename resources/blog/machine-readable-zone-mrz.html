Machine Readable Zone (MRZ): How to Read the MRZ Code on a Passport

The machine readable zone is the two-line code at the bottom of your passport's photo page. What each character means, how MRZ check digits work, where the MRZ sits on passports and ID cards, and why it unlocks the NFC chip in an e-passport.

Hypersign Compliance Team·November 11, 2026·6 min read

An airline check-in form asks you to "enter your name exactly as it appears in the MRZ." You open your passport and find two lines of capital letters and chevrons at the bottom of the photo page. That strip is the machine readable zone, and it is how border scanners, airline kiosks, and identity verification apps read your passport in under a second. Here's what each character means, how the check digits catch errors, and where the MRZ stops being enough.

What Is a Machine Readable Zone?

A machine readable zone (MRZ) is a block of two or three printed lines on a passport, ID card, or visa that holds the holder's core identity data in a fixed format a computer can read. The International Civil Aviation Organization (ICAO) defines the layout in Doc 9303, the global standard for machine readable travel documents.

Every MRZ uses the same small character set: the capital letters A to Z, the digits 0 to 9, and the filler character "<". The text uses OCR-B, a typeface built for optical character recognition. That restriction is the whole point. A scanner never has to guess between accents, lowercase letters, or local scripts, so a reader in Singapore parses a German passport the same way it parses its own.

The MRZ repeats what the visual inspection zone (VIZ) above it already shows: name, nationality, date of birth, sex, document number, and expiry date. It adds check digits, which let a machine confirm it read each field correctly.

Where Is the MRZ Code on a Passport?

The passport machine readable zone sits at the very bottom of the photo data page, below your photo and printed details. It runs edge to edge as two lines of 44 characters each.

On a national ID card, you'll usually find it on the back as three shorter lines. On a visa sticker, it runs along the bottom of the visa itself. If a document has no such strip, it isn't machine readable, and a scanner or app will report "no MRZ detected."

MRZ Formats: TD1, TD2, and TD3

ICAO defines three main sizes of travel document, and each has its own MRZ layout:

FormatLines x charactersTypical documents
TD13 x 30Credit-card-sized national ID cards and residence permits
TD22 x 36Larger ID cards and some older official documents
TD32 x 44Passport booklets

Visas follow two related formats, MRV-A and MRV-B, sized to fit the passport page they're stuck on. The rest of this guide uses the TD3 passport format, since that's what most people mean by "MRZ code on passport."

How to Read the MRZ Code on a Passport

Here is the specimen MRZ that ICAO publishes in Doc 9303, issued by the fictional state of Utopia:

P<UTOERIKSSON<<ANNA<MARIA<<<<<<<<<<<<<<<<<<< L898902C36UTO7408122F1204159ZE184226B<<<<<10

The first line holds the document type, issuing country, and name:

  • P< marks a passport. The second slot can hold a letter for the passport type, or a filler.
  • UTO is the issuing state, as a three-letter ICAO country code.
  • ERIKSSON<<ANNA<MARIA is the name. A double chevron separates the surname from the given names, and a single chevron replaces each space. Fillers pad the line to 44 characters.

The second line holds the numbers, each followed by its own check digit:

  • L898902C3 is the passport number, followed by check digit 6.
  • UTO is the holder's nationality, which can differ from the issuing state.
  • 740812 is the date of birth in YYMMDD format (12 August 1974), followed by check digit 2.
  • F is sex: M, F, or a filler for unspecified.
  • 120415 is the expiry date (15 April 2012), followed by check digit 9.
  • ZE184226B is an optional personal number, padded with fillers and followed by check digit 1.
  • The final 0 is the composite check digit, which covers the passport number, birth date, expiry date, and personal number together.

Passport offices transliterate names with accents or non-Latin scripts, and shorten long names to fit. That's why an airline form wants the MRZ spelling. It's the version every machine at the border will compare against.

How MRZ Check Digits Work

Each check digit comes from a short calculation. Every character gets a number: digits keep their value, A to Z become 10 to 35, and the filler counts as 0. Multiply each character by a repeating weight of 7, 3, 1, add the results, and keep the last digit of the total.

Take the birth date 740812 from the specimen:

  • 7 x 7 = 49, 4 x 3 = 12, 0 x 1 = 0
  • 8 x 7 = 56, 1 x 3 = 3, 2 x 1 = 2
  • 49 + 12 + 0 + 56 + 3 + 2 = 122, so the check digit is 2

If a scanner misreads one digit, say an 8 as a 3, the sum changes and the check digit no longer matches. The software knows to rescan instead of saving a wrong birth date.

What the MRZ Can't Prove on Its Own

Check digits catch reading errors, not forgeries. The formula is public, so anyone who edits a birth date can recalculate the check digit in seconds. Free online MRZ calculators generate valid-looking lines for any data you type in.

A valid MRZ only tells you the strip is internally consistent. To trust the document, a verification system has to go further:

  • Cross-check the MRZ against the VIZ. A forger who edits the printed birth date often forgets the MRZ, or the reverse.
  • Inspect the document image for tampering, font mismatches, and a swapped photo.
  • Read the NFC chip in an e-passport, where the data carries the issuing government's digital signature.
  • Match the holder's face to the photo with a live selfie and liveness check.

The MRZ and the NFC Chip in e-Passports

Most passports issued today are e-passports with an NFC chip in the cover or data page. The MRZ does a second job here: it acts as the key that opens the chip.

Under Basic Access Control (BAC), a reader derives the chip's access key from three MRZ fields: the document number, date of birth, and expiry date, each with its check digit. The newer Password Authenticated Connection Establishment (PACE) protocol can use the same MRZ data. So an app has to read the MRZ first, either by camera or by typing it in, before it can talk to the chip.

That design stops someone from reading your chip from across a room, since they'd need to see the data page first. Once the chip opens, its data is signed by the issuing country, so a forged chip fails signature verification even when the printed MRZ looks perfect.

How to Tell If Your Passport Is Machine Readable

If your passport has the two-line MRZ at the bottom of the photo page, it's machine readable. ICAO set 24 November 2015 as the deadline for every non-machine-readable passport to leave circulation, so any valid passport today should carry one.

A small chip logo on the cover, a rectangle with a circle inside, means it's also an e-passport with an NFC chip. Machine readable and biometric aren't the same thing: every e-passport has an MRZ, but not every machine readable passport has a chip.
